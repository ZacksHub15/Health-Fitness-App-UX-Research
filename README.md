# Health and Fitness Mobile Application – UX Research

## Overview

This academic project explores how User Experience (UX) design can improve user engagement in health and fitness mobile applications.

The research investigates usability challenges and explores how user-centred design principles can improve the experience of people using health and fitness apps.

## Research Objectives

- Explore UX and usability challenges in health and fitness apps.
- Investigate existing UX design guidelines and frameworks.
- Examine how gamification can support user engagement.
- Design a user-friendly mobile application prototype.
- Evaluate the prototype using Nielsen's 10 usability heuristics and WCAG principles.

## Research Methodology

- Research approach: Deductive
- Research philosophy: Interpretivism
- Data collection: Secondary research
- Data analysis: Qualitative analysis

## Tools and Techniques

- Figma
- Nielsen's 10 Usability Heuristics
- WCAG accessibility principles
